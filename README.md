# 开锁实验室 · 向费曼致敬

**在线体验：** https://liyucheng1997.github.io/409_lab-lock-pick/

用 Three.js 把三种常见的锁剖开来，亲手体验开锁原理。

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 产物在 dist/
```

## 三把锁

| 锁 | 能学到什么 | 操作 |
| --- | --- | --- |
| 弹子锁（剖面） | 剪切线、制造公差与绑定顺序、单针挑拨 SPP、过度抬升、防盗弹子假开、耙子、钥匙原理 | 鼠标移到锁上选弹子，按住左键向上拖抬起；`Q`/`E` 调张力 |
| 保险柜拨盘锁 | 轮片组与空转、“左 4 右 3 左 2”、费曼的 ±2 容差、偷看后两位、猜密码、接触点操控 | 拖动拨盘或在拨盘上滚轮；`←`/`→` 每次 1 格，`Shift` 10 格 |
| 数字轮密码锁 | 张力法逐位解码、从缝隙看内套缺口 + 统一偏移 | 在轮子上下拖动；按住空格拉住锁头；`Enter` 试开 |

每把锁右侧都有「原理 / 技法 / 费曼 / 任务」课程，任务进度保存在浏览器本地。

## 代码结构

- `src/core/stage.js` 渲染器、相机、灯光、阴影
- `src/core/csg.js` 布尔建模（three-bvh-csg），剖面使用单独的哑光材质
- `src/core/audio.js` WebAudio 现场合成的机械声
- `src/locks/*.js` 每把锁的建模、机械模拟、交互与课程内容
- `src/ui.js` 右侧面板、手感示波器、提示条

只在属于你自己的锁上练习。
